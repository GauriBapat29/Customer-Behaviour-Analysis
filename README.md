# Customer-Behaviour-Analysis
**Overview**

The project covers the entire lifecycle of a data analysis task, including:
* Loading and inspecting raw data
* Exploratory Data Analysis (EDA)
* Data cleaning and preprocessing
* Executing analytical SQL queries (PostgreSQL / MySQL / SQL Server)
* Building an interactive Power BI dashboard
* Creating a final business report

**Dataset**

The dataset contains customer-related information such as:
* Purchase amounts
* Product ratings
* Number of previous purchases
* Shopping behavior indicators
* Customer id
* Shipping methods

**Tools and Technologies**

* Python (Pandas, NumPy, Matplotlib/Seaborn)
* SQL Database (PostgreSQL / MySQL / SQL Server)
* Power BI (Interactive dashboard)
* Jupyter Notebook
* Gamma (Presentation tool)
* Git and GitHub for version control

**Project Steps**

**1. Data Loading (Python)**
* Loaded the dataset using Pandas
* Performed initial inspection (shape, data types, info, summary statistics)

**2. Exploratory Data Analysis (EDA)**
* Visualizations for customer segments
* Identified trends, correlations, and distributions
* Analyzed revenue patterns

**3. Data Cleaning**

* Handled missing values
* Removed duplicates
* Standardized categorical fields
* Performed feature engineering where needed

**4. SQL Analysis**
* Imported the cleaned dataset into MySQL
* Performed analytical queries such as:
* Customer segmentation
* New vs returning customers
* Revenue analysis
* Purchase frequency
* Product popularity

**5. Power BI Dashboard**

Built an interactive dashboard with filters and slicers
Added visualizations such as:
* Revenue trends
* Created a clear and actionable visual summary

**6. Report and Presentation**

* Compiled insights into a written report
* Created a final presentation using Gamma summarizing the findings
